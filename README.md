# 📄 ResumeForge — Professional ATS Resume Builder

A fully functional, beautifully designed ATS Resume Builder website built with pure HTML, CSS, and JavaScript. No frameworks. No installs. Just open and use.

---

## 🚀 How to Use

1. Put all 4 HTML files in the **same folder**
2. Open `login.html` in your browser
3. Click **"Create one free"** → sign up
4. Log in → click **Open Builder**
5. Fill your resume → click **Generate** → Download PDF or DOCX

---

## 🗂️ Files

```
ResumeForge/
├── login.html       ← Open this first
├── signup.html      ← Create Account
├── dashboard.html   ← Dashboard
├── builder.html     ← Resume Builder
├── README.md
└── LICENSE
```

> ⚠️ All 4 HTML files must be in the **same folder** for navigation to work.

---

## ✨ Features

- Animated particle backgrounds on every page
- Login & Signup with password strength meter
- Live resume preview while filling in details
- ATS-optimized format
- PDF & DOCX export
- Dark / Light mode toggle
- Add / Remove Education, Experience, Projects
- Responsive — works on mobile
